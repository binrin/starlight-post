별빛 우체국 제작 노트

독립 창작 육성 게임

© 2026 체니. 게임 코드, 새 이야기, 캐릭터, 우체국 배경과 UI는 이 프로젝트를 위해 제작했습니다. 프린세스메이커의 실행 파일·리소스·음악·인물·대사·엔딩 문장을 배포물에 포함하지 않았습니다. 다른 게임의 공인 후속작이나 공식 리메이크가 아닙니다.

그림과 도구

승인된 애니풍 참고 그림을 기준으로 OpenAI 이미지 생성 도구를 사용해 이 게임을 위한 2D 캐릭터, 의상, 신발, 장식, 배경, 주민 초상과 엔딩 일러스트를 제작했습니다. 초기 Blender 시안은 최종 게임 그림에 사용하지 않습니다. 이미지 생성 프롬프트와 원본 PNG는 로컬 개발 프로젝트의 art/anime 폴더에 보관했습니다.

투명 레이어를 조합해 의상·신발·장식을 각각 착용하고, 헤어 마스크로 머리카락만 염색합니다. 엔딩 CG는 직업별 고정 일러스트이며 옷장 외형이 반영되지 않습니다. PNG→WebP 변환에는 공개 도구 Pillow를 사용했습니다.

아이콘은 직접 작성한 SVG, 효과음은 Web Audio 합성음입니다. 글꼴은 기기 기본 한글 글꼴을 사용합니다. 외부 폰트·음원·광고·추적 스크립트 없이 작동합니다.

육성 방식의 참고 자료

아래 자료는 장르 연구에 사용했습니다. 등장인물·설정·대사 대신 시스템의 역할을 참고해 새로운 규칙으로 구성했습니다.

프린세스메이커2 공식 소개 — 일상 선택이 능력과 여러 미래로 이어지는 육성 구조. 본 게임은 나이와 기간으로 강제 종료하지 않습니다.

프린세스메이커3 공식 소개 — 수업별 라이벌·이벤트, 앨범을 참고해 계절 라이벌 축제와 엔딩 도감을 구성했습니다.

프린세스메이커5 공식 소개 — 교육 방침, 공부·일·스트레스의 균형에서 착안해 네 가지 육성 방침과 피로에 따른 효율 변화를 구현했습니다.

화산의 딸 공식 소개 — 취미·직업·다양한 활동과 시민들과의 관계에서 착안해 특성, 친구별 추억, 의뢰, 지역별 탐험을 구성했습니다.

저장과 배포

진행은 기기 브라우저의 로컬 저장소에 보관합니다. 자동 백업과 JSON 파일 내보내기·가져오기를 지원합니다. 서버 계정이나 기기 간 자동 동기화는 사용하지 않습니다. PWA는 Safari·Chrome에서 홈 화면에 설치할 수 있습니다. 앱스토어·플레이스토어 등록 앱은 아닙니다.
